# 🚀 QuickShare P2P

A modern, fast, and secure peer-to-peer file sharing application with real-time chat.

## ✨ Features

- **Direct P2P Transfer**: Files transfer directly between devices
- **Real-time Chat**: Built-in encrypted messaging
- **No Size Limits**: Transfer any size file
- **No Signup Required**: Start sharing immediately
- **Cross-platform**: Works on desktop & mobile
- **End-to-end Encryption**: Your data stays private

## 🛠️ Tech Stack

**Frontend:**
- React + Vite
- Tailwind CSS
- Socket.io Client
- WebRTC

**Backend:**
- Node.js + Express
- Socket.io
- Render (Hosting)
